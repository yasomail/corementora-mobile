# Corementora Reçus

Appli web installable (Android et iPhone) pour photographier les reçus de dépenses.
Elle lit sur le téléphone la date, le fournisseur et le montant, nomme le PDF selon la
convention de l'archive Pigiste-BNC et l'envoie dans Google Drive, dossier `_A-classer`.
L'application de bureau Corementora le range ensuite au bon endroit.

Ce dépôt contient seulement la version compilée publiée sur GitHub Pages :
https://yasomail.github.io/corementora-mobile/

Aucune donnée ni aucun reçu n'est stocké ici. La lecture du texte se fait sur le téléphone
(Tesseract, licence Apache 2.0).
